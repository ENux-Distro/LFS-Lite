Chapter 8. GRUB Setup

The Grand Unified Bootloader (GRUB) is the component responsible for loading the kernel. It runs before the kernel, provides a boot menu, loads the kernel image and initramfs into memory, and passes boot parameters to the kernel. GRUB supports both BIOS (legacy) and UEFI boot modes; this chapter focuses on BIOS mode.

Approximate build time: 5–10 minutes
Required disk space: ~120 MB
Source tarball: grub-2.14.tar.xz

8.1. Introduction to GRUB

Unlike the other packages in this book, GRUB itself runs before the operating system — before musl, before bash, before any userspace. It therefore does not link against musl and does not use the musl-gcc wrapper. GRUB is compiled as a standard host tool and installed on the host, where the installer script will later invoke it to set up the target disk.

GRUB's boot process has two stages:

  • Stage 1 (446 bytes in the MBR): loads Stage 2 from the boot gap between the MBR and the first partition.
  • Stage 2 (in /boot/grub/): has a full filesystem driver, reads grub.cfg, displays the menu, and loads the kernel.

8.2. Extracting the Source

cd $LFS_SOURCES
tar -xJf grub-2.14.tar.xz
cd grub-2.14

8.3. Configuring GRUB

./configure \
    --prefix=/usr \
    --sysconfdir=/etc \
    --disable-efiemu \
    --disable-werror \
    --disable-grub-manpages \
    --target=x86_64

The meaning of the configure options:

--disable-efiemu

Disables the EFI emulator component, which is not needed for a BIOS installation.

--disable-werror

GRUB's code may generate warnings with newer compilers. This flag prevents warnings from being treated as fatal errors, allowing the build to complete.

--disable-grub-manpages

Skips generation of man pages. Man page generation requires help2man on the host, which is not a standard build dependency and is not listed in the host system requirements. GRUB's man pages document its command-line tools for the installed system; they have no bearing on whether the bootloader itself functions correctly.

--target=x86_64

Build GRUB for the x86_64 platform.

8.4. Compiling GRUB

make -j${JOBS}

8.5. Installing GRUB

GRUB must be installed in two places:

  • The host system — so the installer script in Chapter 12 can call grub-install to write the bootloader to the target disk's MBR.
  • The LFS-Lite root — so the booted system has GRUB tools available for maintenance (re-running grub-install after a disk change, updating grub.cfg, etc.).
sudo make install
make DESTDIR=$LFS_ROOT install

grub-mkconfig is not installed by make install as part of the standard GRUB build. Copy it manually from the host installation: 

sudo cp -v /usr/bin/grub-mkconfig $LFS_ROOT/usr/bin/grub-mkconfig

Verify the host installation:

grub-install --version
grub-mkconfig --version

Verify the LFS-Lite root installation:

ls $LFS_ROOT/usr/sbin/grub-install
ls $LFS_ROOT/usr/bin/grub-mkconfig

8.6. GRUB Configuration File for the Live ISO

Create the grub.cfg for the live ISO. This file is what GRUB reads when booting from the ISO image. It must load the kernel and initramfs from the optical medium — it does not specify a root disk device, because on a live ISO there is no installed root partition. The initramfs /init script (Chapter 9) is responsible for mounting the live medium and calling switch_root.

Note

This is not the same grub.cfg that the installer writes to a hard disk. The installer script in Chapter 12 generates a separate configuration with UUID-based root= parameters for the installed system. The file created here is only for booting the ISO. 

mkdir -pv $LFS_ROOT/boot/grub

cat > $LFS_ROOT/boot/grub/grub.cfg << "EOF"
# LFS-Lite live ISO GRUB configuration
set default=0
set timeout=5

insmod iso9660
insmod all_video

menuentry "LFS-Lite Linux 7.1.2 (Live)" {
    linux  /vmlinuz-7.1.2 quiet
    initrd /initramfs.cpio.gz
}

menuentry "LFS-Lite Linux 7.1.2 (Live, verbose)" {
    linux  /vmlinuz-7.1.2
    initrd /initramfs.cpio.gz
}
EOF

Key grub.cfg directives:

insmod iso9660

Loads the ISO 9660 filesystem module so GRUB can read files from the optical medium. On an ISO, there is no part_msdos or ext2 involved at the GRUB stage.

linux /vmlinuz-7.1.2 quiet

Loads the kernel from the ISO's root. No root= device is passed here — the live initramfs is self-contained and locates the root medium itself. Passing a hardcoded device path such as root=/dev/sda2 would be incorrect: the ISO has no such partition, and the device name would be wrong on most machines anyway.

initrd /initramfs.cpio.gz

The initramfs archive. The kernel extracts this into a tmpfs and executes /sbin/init inside it as PID 1.
