Chapter 8. GRUB Setup

The Grand Unified Bootloader (GRUB) is the component responsible for loading the kernel. It runs before the kernel, provides a boot menu, loads the kernel image and initramfs into memory, and passes boot parameters to the kernel. GRUB supports both BIOS (legacy) and UEFI boot modes; this chapter focuses on BIOS mode.

Approximate build time: 5–10 minutes
Required disk space: ~120 MB
Source tarball: grub-2.14.tar.xz

8.1. Introduction to GRUB

Unlike the other packages in this book, GRUB itself runs before the operating system — before musl, before bash, before any userspace. It therefore does not link against musl and does not use the musl-gcc wrapper. GRUB is compiled as a standard host tool and installed on the host, where the installer script will later invoke it to set up the target disk.

GRUB's boot process has two stages:

  • Stage 1 (446 bytes in the MBR): loads Stage 2 from the boot gap between the MBR and the first partition.
  • Stage 2 (in /boot/grub/): has a full filesystem driver, reads grub.cfg, displays the menu, and loads the kernel.

8.2. Extracting the Source

cd $LFS_SOURCES
tar -xJf grub-2.14.tar.xz
cd grub-2.14

8.3. Configuring GRUB

./configure \
    --prefix=/usr \
    --sysconfdir=/etc \
    --disable-efiemu \
    --disable-werror \
    --target=x86_64

The meaning of the configure options:

--disable-efiemu

Disables the EFI emulator component, which is not needed for a BIOS installation.

--disable-werror

GRUB's code may generate warnings with newer compilers. This flag prevents warnings from being treated as fatal errors, allowing the build to complete.

--target=x86_64

Build GRUB for the x86_64 platform.

8.4. Compiling GRUB

make -j${JOBS}

8.5. Installing GRUB to the Host

Install GRUB to the host system. It will be invoked by the installer script (Chapter 12) to write the bootloader to the target disk's MBR. 

sudo make install

Verify:

grub-install --version
grub-mkconfig --version

8.6. GRUB Configuration File

Create the template grub.cfg that will be placed in the target system's /boot/grub/. The installer script in Chapter 12 will adapt this template with the correct UUIDs for the target disk's partitions. 

mkdir -pv $LFS_ROOT/boot/grub

cat > $LFS_ROOT/boot/grub/grub.cfg << "EOF"
# LFS-Lite GRUB configuration
set default=0
set timeout=5

insmod part_msdos
insmod ext2
insmod all_video

menuentry "LFS-Lite Linux 7.1.2" {
    set root=(hd0,1)
    linux  /vmlinuz-7.1.2 root=/dev/sda2 rw quiet
    initrd /initramfs.cpio.gz
}

menuentry "LFS-Lite Linux 7.1.2 (verbose)" {
    set root=(hd0,1)
    linux  /vmlinuz-7.1.2 root=/dev/sda2 rw
    initrd /initramfs.cpio.gz
}
EOF

Key grub.cfg directives:

set root=(hd0,1)

GRUB disk numbering starts at 0; partition numbering starts at 1. (hd0,1) is the first partition of the first disk — the /boot partition. The installer replaces this with a UUID-based search command for robustness.

root=/dev/sda2

Tells the kernel where to find the real root filesystem. The installer replaces the device path with root=UUID=... so the system boots correctly regardless of disk ordering.

initrd /initramfs.cpio.gz

The initramfs archive. The kernel loads this into memory and extracts it before executing the first userspace process.

Note

Paths in grub.cfg are relative to the GRUB root device, not to the running system root. When /boot is a separate partition (as the installer creates), files must be referenced as /vmlinuz-7.1.2 — not /boot/vmlinuz-7.1.2.
