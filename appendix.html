Appendix

This appendix collects quick-reference material used throughout the book: command summaries, flag meanings, package version tables, kernel option references, and comparisons between the key technical choices made in LFS-Lite.

Appendix A — Essential Command Reference

Source Extraction

tar -xzf package.tar.gz      # gzip-compressed
tar -xJf package.tar.xz      # xz-compressed
tar -xjf package.tar.bz2     # bzip2-compressed

Standard Build Sequence

./configure [options]
make -j$(nproc)
make check           # optional but strongly recommended
make DESTDIR=$LFS_ROOT install

initramfs Operations

# Create a gzipped cpio archive from a staging directory
find $INITRAMFS | cpio --create --format=newc | gzip -9 > initramfs.cpio.gz

# List contents of an existing archive
zcat initramfs.cpio.gz | cpio --list

# Extract an archive into the current directory
zcat initramfs.cpio.gz | cpio --extract --make-directories

Disk Operations

lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINT   # List block devices
blkid /dev/sdX1                         # Show UUID of a partition
wipefs -a /dev/sdX                      # Erase partition table
mkfs.ext4 -L label /dev/sdX1           # Format partition as ext4
fdisk -l /dev/sdX                       # Show partition table

Chroot Setup and Teardown

# Enter chroot
sudo mount --bind /proc $LFS_ROOT/proc
sudo mount --bind /sys  $LFS_ROOT/sys
sudo mount --bind /dev  $LFS_ROOT/dev
sudo chroot $LFS_ROOT /usr/bin/bash --login

# Exit and clean up
sudo umount $LFS_ROOT/dev
sudo umount $LFS_ROOT/sys
sudo umount $LFS_ROOT/proc

Kernel Configuration Shortcuts

# Enable an option
scripts/config --enable  CONFIG_EXT4_FS

# Disable an option
scripts/config --disable CONFIG_SOUND

# Set a string value
scripts/config --set-str CONFIG_DEFAULT_HOSTNAME "lfslite"

# Check current value
grep CONFIG_EXT4_FS .config

Environment Variable Quick-Reference

export LFS=/mnt/lfs-lite
export LFS_SOURCES=$LFS/sources
export LFS_ROOT=$LFS/rootfs
export LFS_TOOLS=$LFS/tools
export INITRAMFS=$LFS/initramfs
export JOBS=$(nproc)
export LFS_LOG=$LFS/logs/build-$(date +%Y%m%d-%H%M).log

Appendix F — Further Reading

  • Linux From Scratch (linuxfromscratch.org) — The complete guide to building a full Linux system from source. LFS-Lite draws its methodology directly from LFS.
  • Beyond Linux From Scratch — Extends a base LFS system with networking, X.org, and many additional packages.
  • musl libc documentation (musl.libc.org) — Comprehensive documentation of musl's behaviour, compatibility notes, and design rationale.
  • BusyBox documentation (busybox.net) — Reference for BusyBox applet behaviour and Kconfig options.
  • The Linux Kernel documentation (kernel.org/doc) — Authoritative reference for kernel configuration, system calls, and subsystem internals.
  • GNU GRUB manual (gnu.org/software/grub/manual) — Complete GRUB configuration and scripting reference.
  • Filesystem Hierarchy Standard (refspecs.linuxfoundation.org) — Defines the conventions LFS-Lite partially follows.
  • The runit init system (smarden.org/runit) — An excellent reference for minimal but correct service supervision, suitable as an extension to LFS-Lite's init.

Appendix G — QEMU Quick-Start

LFS-Lite ships as a live ISO. Boot it directly in QEMU without any disk image or installer: 

# Boot the live ISO in QEMU (graphical window)
qemu-system-x86_64 \
    -m 512M \
    -cdrom ~/ENux-6.0/enux-lfs-lite.iso \
    -boot d

# Boot with serial console only (no GUI window needed)
qemu-system-x86_64 \
    -m 512M \
    -cdrom ~/ENux-6.0/enux-lfs-lite.iso \
    -boot d \
    -nographic \
    -append "console=ttyS0"

To test the installer (Chapter 12) inside QEMU, create a target disk image and attach it alongside the ISO: 

# Create a 4 GB raw disk image as the install target
qemu-img create -f raw /tmp/lfslite-disk.img 4G

# Boot the live ISO with the disk image attached
# The ISO is /dev/sr0; the disk image becomes /dev/sda (the install target)
qemu-system-x86_64 \
    -m 512M \
    -cdrom ~/ENux-6.0/enux-lfs-lite.iso \
    -drive file=/tmp/lfslite-disk.img,format=raw,if=virtio \
    -boot d \
    -nographic \
    -append "console=ttyS0"

# Inside the live system, run the installer:
#   sudo /mnt/lfs-lite/install.sh /dev/vda

Note

With -drive if=virtio, the disk image appears as /dev/vda inside the guest, not /dev/sda. Pass /dev/vda to the installer. The installed system's grub.cfg uses root=UUID=... so the device name does not matter after installation.
