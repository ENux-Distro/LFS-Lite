Chapter 5. Building util-linux

util-linux is the standard collection of Linux system utilities, providing essential tools for disk partitioning, filesystem operations, system information, terminal control, and miscellaneous system functions. Many of these tools interact directly with kernel interfaces and require correct compile-time knowledge of the target kernel's ABI.

Approximate build time: 4–8 minutes
Required disk space: ~250 MB
Source tarball: util-linux-2.42.tar.xz

5.1. Introduction to util-linux

Among the tools provided by util-linux are:

  • Disk partitioning: fdisk, sfdisk, cfdisk
  • Filesystem operations: mount, umount, blkid, lsblk, findmnt
  • System information: lscpu, lsmem, dmesg
  • Miscellaneous: kill, flock, nsenter, unshare

5.2. Installing Kernel Headers

Before building util-linux, the target kernel headers must be installed into the sysroot. These headers define the ABI structures that util-linux tools use when interacting with the kernel. Extract and install them from the kernel source: 

cd $LFS_SOURCES
tar -xJf linux-7.1.2.tar.xz
cd linux-7.1.2

make mrproper
make headers
find usr/include -name '.*' -delete
rm usr/include/Makefile
cp -rv usr/include $LFS_ROOT/usr/

Explanation of commands:

make mrproper

Ensures a completely clean state, removing any previous build artefacts or configuration files.

make headers

Generates the sanitised kernel headers — the uapi headers that are safe to export to userspace programs. These are distinct from the in-tree kernel headers used during kernel compilation itself.

Verify:

ls $LFS_ROOT/usr/include/linux/types.h

5.3. Extracting util-linux

cd $LFS_SOURCES
tar -xJf util-linux-2.42.tar.xz
cd util-linux-2.42

5.4. Configuring util-linux

util-linux is a large package with many optional components. We configure it to build only the tools needed for a minimal system, disabling those that require PAM, Python, ncurses, or systemd: 

./configure \
    --prefix=/usr \
    --host=x86_64-linux-musl \
    --build=$(config/config.guess) \
    --disable-chfn-chsh \
    --disable-login \
    --disable-nologin \
    --disable-su \
    --disable-setpriv \
    --disable-runuser \
    --disable-pylibmount \
    --disable-static \
    --disable-liblastlog2 \
    --without-python \
    --without-systemd \
    --without-systemdsystemunitdir \
    --without-ncurses \
    --without-tinfo \
    CC="$LFS_TOOLS/musl-gcc" \
    CFLAGS="-O2 -pipe" \
    CPPFLAGS="-I$LFS_ROOT/usr/include" \
    LDFLAGS="-L$LFS_ROOT/usr/lib -L$LFS_ROOT/lib64"

The meaning of selected configure options:

--disable-chfn-chsh, --disable-login, --disable-su

These tools require PAM (Pluggable Authentication Modules), which is not in LFS-Lite's scope. Disabling them avoids a complex and large dependency.

--disable-static

For util-linux we build shared libraries and dynamically linked binaries. The tools are large enough that the space overhead of static linking across many binaries outweighs the convenience for this package.

--without-systemd

util-linux can optionally install systemd unit files. We have no systemd; this flag prevents the build system from searching for it.

--without-ncurses, --without-tinfo

Disables ncurses-dependent features in tools like cfdisk. We accept simpler terminal output to avoid the ncurses dependency.

CPPFLAGS

Points the C preprocessor at our sysroot's kernel headers, ensuring util-linux compiles against the correct Linux ABI definitions.

5.5. Compiling util-linux

make -j${JOBS}

5.6. Installing util-linux

make DESTDIR=$LFS_ROOT install

Verify that key tools are present:

ls $LFS_ROOT/usr/bin/mount
ls $LFS_ROOT/usr/bin/umount
ls $LFS_ROOT/usr/sbin/fdisk
ls $LFS_ROOT/usr/bin/blkid
ls $LFS_ROOT/usr/bin/dmesg
ls $LFS_ROOT/usr/bin/lsblk

With util-linux installed, the final system now has all the tools necessary to manage disks and filesystems interactively. Proceed to Chapter 6 to build BusyBox for the initramfs.
