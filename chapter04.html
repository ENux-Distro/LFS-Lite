Chapter 4. Building bash

The Bourne Again SHell (Bash) is the default interactive shell and scripting language for the vast majority of Linux systems. It is the shell that users interact with directly and the interpreter for the init scripts, installer, and other shell-based components in LFS-Lite. Without bash, the system has no interactive interface and no scripting capability.

Approximate build time: 3–6 minutes
Required disk space: ~60 MB
Source tarball: bash-5.3.tar.gz

4.1. Introduction to Bash

Bash 5.3 is a feature-complete, POSIX-conformant shell with extensions for interactive use (command history, job control, tab completion) and scripting (arrays, arithmetic, process substitution). It depends on:

  • A C standard library — provided by musl.
  • The readline library for command-line editing. bash bundles its own copy, which we will use to avoid an external dependency.

4.2. Extracting the Source

cd $LFS_SOURCES
tar -xzf bash-5.3.tar.gz
cd bash-5.3

4.3. Configuring bash

./configure \
    --prefix=/usr \
    --host=x86_64-linux-musl \
    --build=$(support/config.guess) \
    --without-bash-malloc \
    --with-installed-readline=no \
    --enable-static-link \
    CC="$LFS_TOOLS/musl-gcc" \
    CFLAGS="-O2 -pipe" \
    LDFLAGS="-static"

The meaning of the configure options:

--without-bash-malloc

Disables bash's custom memory allocator and uses the one provided by musl instead. Bash's allocator is a historical optimisation that predates modern libc allocators; musl's implementation is superior for our purposes.

--with-installed-readline=no

Uses bash's bundled readline copy rather than searching for a system readline library. This avoids a potential dependency on the host system's readline headers and ensures a self-contained build.

--enable-static-link

Instructs bash's build system to produce a statically linked binary. The resulting bash carries musl libc inside it and works correctly before the dynamic linker is operational — important for early-boot init scripts.

4.4. Compiling bash

make -j${JOBS}

Note

Bash's build is not as parallelisable as coreutils — many of its sub-components have serial dependencies. Expect the build to take longer per-core than previous packages.

4.5. Installing bash

make DESTDIR=$LFS_ROOT install

Create the traditional /bin/sh and /usr/bin/sh symlinks: 

ln -sfv bash $LFS_ROOT/usr/bin/sh

Because $LFS_ROOT/bin is already a symlink to usr/bin, this also provides /bin/sh in the final system without any additional steps.

Verify the installation:

file $LFS_ROOT/usr/bin/bash
ls -la $LFS_ROOT/usr/bin/sh

The file output should confirm the binary is statically linked. The symlink should point to bash.

Note on Static Linking and Shell Scripts

At 2–4 MB, a statically linked bash is entirely acceptable for a minimal system. The benefit is significant: bash will work correctly in environments where the dynamic linker is not yet operational — including the initramfs stage and the earliest moments of the final init script, before /lib64 is accessible.
