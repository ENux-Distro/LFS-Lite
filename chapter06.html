Chapter 6. Building BusyBox for initramfs

BusyBox is sometimes described as “the Swiss Army knife of embedded Linux.” It provides over 300 Unix utilities in a single, small, statically linked binary. In LFS-Lite, BusyBox serves a specific and bounded role: it populates the initramfs. It is not present in the final root filesystem.

Approximate build time: 3–6 minutes
Required disk space: ~60 MB (build), ~1–2 MB (binary)
Source: git clone from git.busybox.net/busybox

6.1. Introduction to BusyBox

At runtime, calling busybox ls invokes the ls implementation inside BusyBox. Creating a symlink named ls that points to the busybox binary achieves the same effect transparently — the binary inspects argv[0] to determine which applet to run.

The initramfs needs a shell, basic file utilities, and the switch_root command. BusyBox provides all of these in a single binary. Once the system pivots into the real root (which has GNU coreutils, bash, and util-linux), BusyBox is no longer needed and is not present.

6.2. Updating the BusyBox Source

cd $LFS_SOURCES/busybox
git pull

Check the version that will be built:

head -5 Makefile

6.3. Configuring BusyBox

BusyBox uses a kernel-style Kconfig build system. Start from the default configuration: 

make defconfig

Apply the critical configuration changes programmatically: 

# Enable static linking — essential for initramfs portability
sed -i 's/# CONFIG_STATIC is not set/CONFIG_STATIC=y/' .config

# Verify switch_root is enabled (present in defconfig, but confirm)
grep -q 'CONFIG_SWITCH_ROOT=y' .config || \
    echo 'CONFIG_SWITCH_ROOT=y' >> .config

# Disable utmp/wtmp — not needed in initramfs, avoids musl edge cases
sed -i 's/CONFIG_FEATURE_WTMP=y/# CONFIG_FEATURE_WTMP is not set/' .config
sed -i 's/CONFIG_FEATURE_UTMP=y/# CONFIG_FEATURE_UTMP is not set/' .config

# Append extra compiler flags
cat >> .config << "EOF"
CONFIG_EXTRA_CFLAGS="-O2 -pipe"
EOF

Note

For interactive configuration, run make menuconfig after make defconfig. The most important option to verify is CONFIG_STATIC=y under Settings → Build Options.

6.4. Compiling BusyBox

make -j${JOBS} \
    CC="$LFS_TOOLS/musl-gcc" \
    CFLAGS="-O2 -pipe" \
    LDFLAGS="-static"

The build produces a single binary: busybox. Verify it is statically linked and check its size: 

file busybox
ldd busybox 2>&1 | grep -i "not a dynamic"
ls -lh busybox

A typical LFS-Lite BusyBox binary ranges from 700 KB to 2 MB depending on which applets are enabled.

6.5. Installing BusyBox for initramfs

Install BusyBox into a dedicated initramfs staging directory — not into $LFS_ROOT: 

export INITRAMFS=$LFS/initramfs
mkdir -pv $INITRAMFS/{bin,dev,etc,lib,lib64,mnt/root,proc,root,sbin,sys,tmp}

cp -v busybox $INITRAMFS/bin/busybox
chmod +x $INITRAMFS/bin/busybox

Create applet symlinks for every tool the initramfs /init script requires: 

for applet in sh ash cat cp ls mkdir mount umount mdev \
              switch_root grep sed awk find echo printf \
              sleep dmesg; do
    ln -sfv busybox $INITRAMFS/bin/$applet
done

Verify BusyBox is functional in the staging area:

$INITRAMFS/bin/busybox echo "BusyBox is operational."
$INITRAMFS/bin/sh -c "echo 'sh applet works'"

Note

The $INITRAMFS variable must be set whenever you open a new terminal and need to work with the initramfs staging directory. Add export INITRAMFS=/mnt/lfs-lite/initramfs to your ~/.bashrc alongside the other LFS variables.
