Chapter 7. Linux Kernel Compilation

The Linux kernel is the core of the operating system. It manages hardware resources, provides the system call interface that userspace programs use, and handles process scheduling, memory management, and device I/O. Everything else in LFS-Lite runs on top of the kernel.

Kernel compilation is the most time-consuming step in this book. The kernel has thousands of configuration options; this chapter presents a minimal but functional configuration for x86_64 systems and QEMU virtual machines.

Approximate build time: 15–60 minutes (hardware dependent)
Required disk space: ~1.5 GB
Source tarball: linux-7.1.2.tar.xz

7.1. Introduction

The compiled kernel consists of three primary outputs:

  • arch/x86/boot/bzImage — the compressed, bootable kernel image. GRUB loads this file.
  • System.map — the kernel symbol table. Not required to boot, but invaluable for diagnosing kernel panics.
  • lib/modules/7.1.2/ — compiled kernel modules. Loadable modules allow the kernel to support hardware not compiled in, without recompiling the entire kernel.

7.2. Extracting the Kernel Source

Note

If you already extracted the kernel source in Section 5.2 to install kernel headers, the directory $LFS_SOURCES/linux-7.1.2 already exists. Skip the extraction and proceed directly to make mrproper. 

cd $LFS_SOURCES
tar -xJf linux-7.1.2.tar.xz
cd linux-7.1.2

make mrproper

7.3. Kernel Configuration

Begin with the x86_64 default configuration: 

make x86_64_defconfig

Then apply the options required for initramfs support, the filesystems LFS-Lite uses, and VirtIO devices for QEMU: 

scripts/config --enable  CONFIG_BLK_DEV_INITRD
scripts/config --enable  CONFIG_TMPFS
scripts/config --enable  CONFIG_DEVTMPFS
scripts/config --enable  CONFIG_DEVTMPFS_MOUNT
scripts/config --enable  CONFIG_EXT4_FS
scripts/config --enable  CONFIG_VIRTIO_BLK
scripts/config --enable  CONFIG_VIRTIO_PCI
scripts/config --enable  CONFIG_VIRTIO_NET
scripts/config --enable  CONFIG_ATA
scripts/config --enable  CONFIG_ATA_PIIX
scripts/config --set-str CONFIG_DEFAULT_HOSTNAME "lfslite"

The meaning of critical kernel options:

CONFIG_BLK_DEV_INITRD

Support for loading an initial RAM disk/filesystem. Required for LFS-Lite's two-stage boot model.

CONFIG_DEVTMPFS + CONFIG_DEVTMPFS_MOUNT

Causes the kernel to auto-populate and auto-mount /dev early in boot. Greatly simplifies the initramfs init script.

CONFIG_EXT4_FS

ext4 filesystem support — used for both the /boot and root partitions.

CONFIG_VIRTIO_BLK / CONFIG_VIRTIO_PCI

Required for disk access and PCI bus emulation in QEMU with VirtIO. Without these, a QEMU VM cannot see its disk.

CONFIG_ATA + CONFIG_ATA_PIIX

IDE/SATA driver for bare-metal hardware. Covers most SATA controllers found in consumer systems.

For interactive configuration, run make menuconfig after applying the above options. Verify each setting is correct before proceeding.

7.4. Compiling the Kernel

make -j${JOBS}

Warning

Kernel compilation is the most resource-intensive step in this book. On an 8-core machine with -j8, expect 15 to 45 minutes. On a 4-core machine, budget an hour. Watch for errors — the kernel build system is noisy but errors are clearly indicated with ERROR or FAILED lines.

7.5. Installing the Kernel and Modules

Install the kernel image, System.map, and modules: 

mkdir -pv $LFS_ROOT/boot

cp -v arch/x86/boot/bzImage $LFS_ROOT/boot/vmlinuz-7.1.2
cp -v System.map            $LFS_ROOT/boot/System.map-7.1.2

make modules_install INSTALL_MOD_PATH=$LFS_ROOT

Verify:

ls -lh $LFS_ROOT/boot/vmlinuz-7.1.2
ls $LFS_ROOT/lib/modules/

A typical LFS-Lite kernel image (bzImage) is 8–12 MB compressed. If it is significantly smaller, a required option may have been left disabled. If it is much larger than 20 MB, the default configuration has included many drivers that can be trimmed with make menuconfig for a leaner result.
