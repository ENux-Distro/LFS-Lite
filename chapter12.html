Chapter 12. Building the Bootable ISO

This chapter assembles everything built in the previous chapters into a single bootable ISO image. The kernel, initramfs, and root filesystem squashfs are placed into a staging directory; GRUB is embedded as the bootloader; and xorriso writes the final hybrid ISO that boots from both optical drives and USB media.

Approximate time: 2–5 minutes
Required disk space: ~200 MB for the ISO staging tree
Tools required: xorriso, grub-mkrescue (from GRUB, Chapter 8), mksquashfs

12.1. How the Live ISO Works

A live ISO does not install anything to disk. When booted, GRUB loads the kernel and the initramfs into memory. The initramfs /sbin/init script mounts the squashfs image from the ISO as a loop device, then calls switch_root to pivot into it. From that point on, the system runs entirely from RAM — the ISO medium can be removed after boot.

The ISO contains the following layout:

iso-root/
├── boot/
│   ├── grub/
│   │   └── grub.cfg
│   ├── vmlinuz-7.1.2
│   └── initramfs.cpio.gz
└── live/
    └── filesystem.squashfs

12.2. Installing Required Tools

xorriso and squashfs-tools must be present on the host. Install them if necessary: 

# Debian / Ubuntu / ENux
sudo apt-get install xorriso squashfs-tools

# Fedora / RHEL
sudo dnf install xorriso squashfs-tools

# Arch Linux
sudo pacman -S xorriso squashfs-tools

Verify:

xorriso --version
mksquashfs -version

12.3. Compressing the Root Filesystem

The root filesystem at $LFS_ROOT is compressed into a squashfs image. squashfs is a read-only compressed filesystem format; the kernel mounts it directly from the ISO via a loop device at boot time. 

mkdir -pv $LFS/iso-root/live

mksquashfs $LFS_ROOT $LFS/iso-root/live/filesystem.squashfs \
    -comp zstd \
    -e $LFS_ROOT/proc \
    -e $LFS_ROOT/sys \
    -e $LFS_ROOT/dev \
    -e $LFS_ROOT/tmp \
    -noappend

The meaning of the mksquashfs options:

-comp zstd

Uses Zstandard compression. zstd offers better compression ratios than gzip and much faster decompression, which reduces RAM pressure when the kernel decompresses the squashfs at mount time.

-e proc sys dev tmp

Excludes the virtual filesystem mount points. These directories are empty at build time and must not be baked into the squashfs; the init script mounts them fresh at every boot.

-noappend

Overwrites any existing squashfs image rather than appending to it. Safe to re-run during iteration.

Verify the squashfs was created and check its size:

ls -lh $LFS/iso-root/live/filesystem.squashfs

12.4. Assembling the ISO Staging Tree

Copy the kernel and initramfs into the ISO staging directory, then write the GRUB configuration: 

mkdir -pv $LFS/iso-root/boot/grub

# Kernel
cp -v $LFS_ROOT/boot/vmlinuz-7.1.2 $LFS/iso-root/boot/

# initramfs
cp -v $LFS/initramfs.cpio.gz $LFS/iso-root/boot/

# GRUB configuration
cat > $LFS/iso-root/boot/grub/grub.cfg << "EOF"
# LFS-Lite live ISO — GRUB configuration
set default=0
set timeout=5

insmod iso9660
insmod all_video

menuentry "LFS-Lite Linux 7.1.2 (Live)" {
    linux  /boot/vmlinuz-7.1.2 quiet
    initrd /boot/initramfs.cpio.gz
}

menuentry "LFS-Lite Linux 7.1.2 (Live, verbose)" {
    linux  /boot/vmlinuz-7.1.2
    initrd /boot/initramfs.cpio.gz
}
EOF

Note

No root= parameter is passed to the kernel. The live initramfs locates and mounts the squashfs itself; it does not depend on the kernel to identify the root device.

12.5. Updating the initramfs for Live Boot

The initramfs /sbin/init built in Chapter 9 must mount the squashfs from the ISO before calling switch_root. Update it now to add squashfs and loop mount support: 

cat > $LFS/initramfs/sbin/init << 'EOF'
#!/bin/sh
# LFS-Lite live initramfs init — PID 1

mount -t proc     none /proc
mount -t sysfs    none /sys
mount -t devtmpfs none /dev

# Allow kernel time to register the optical drive
sleep 1

# Find the live medium (CD-ROM or USB)
for dev in /dev/sr0 /dev/sr1 /dev/sda /dev/sdb /dev/vda; do
    [ -b "$dev" ] || continue
    mount -o ro "$dev" /mnt 2>/dev/null && LIVE_DEV="$dev" && break
done

if [ -z "$LIVE_DEV" ]; then
    echo "ERROR: Could not find live medium. Dropping to shell."
    exec sh
fi

# Mount the squashfs root
if [ ! -f /mnt/live/filesystem.squashfs ]; then
    echo "ERROR: filesystem.squashfs not found on $LIVE_DEV. Dropping to shell."
    exec sh
fi

mkdir -p /mnt/root
mount -t squashfs -o loop /mnt/live/filesystem.squashfs /mnt/root

# Switch into the real root
umount /proc /sys /dev
exec switch_root /mnt/root /sbin/init
EOF
chmod +x $LFS/initramfs/sbin/init

Rebuild the initramfs to pick up the updated init script: 

cd $LFS/initramfs
find . | cpio --create --format=newc | gzip -9 > $LFS/initramfs.cpio.gz
cp -v $LFS/initramfs.cpio.gz $LFS/iso-root/boot/

Note

The loop mount (mount -t squashfs -o loop) requires CONFIG_BLK_DEV_LOOP=y in the kernel. Verify it is set in your kernel configuration: 

grep BLK_DEV_LOOP $LFS_SOURCES/linux-7.1.2/.config

If it is absent, add it with scripts/config --enable BLK_DEV_LOOP and recompile the kernel (Chapter 7).

12.6. Building the ISO with xorriso

xorriso assembles the ISO staging tree into a hybrid image. The hybrid flag makes the ISO bootable from both optical drives and USB sticks written with dd. 

grub-mkrescue \
    --output=$LFS/lfs-lite.iso \
    $LFS/iso-root

grub-mkrescue is a thin wrapper around xorriso that embeds the correct GRUB El Torito boot record and hybrid MBR automatically. It reads your boot/grub/grub.cfg from the staging tree.

Verify the ISO was created:

ls -lh $LFS/lfs-lite.iso
file $LFS/lfs-lite.iso

The file command should report something similar to: 

lfs-lite.iso: ISO 9660 CD-ROM filesystem data (DOS/MBR boot sector) 'LFS-LITE' …

12.7. Testing the ISO in QEMU

Boot the ISO directly in QEMU to verify the full boot chain before writing it to physical media: 

# Graphical boot
qemu-system-x86_64 \
    -m 512M \
    -cdrom $LFS/lfs-lite.iso \
    -boot d

# Serial console (no display required)
qemu-system-x86_64 \
    -m 512M \
    -cdrom $LFS/lfs-lite.iso \
    -boot d \
    -nographic \
    -append "console=ttyS0"

You should see the GRUB menu, then kernel boot messages, then the initramfs locating and mounting the squashfs, and finally a bash prompt from the final root filesystem.

12.8. Writing the ISO to Physical Media

To boot LFS-Lite on real hardware, write the ISO to a USB stick or burn it to a DVD. Identify the USB device with lsblk, then:

Warning

The dd command below will overwrite every byte on the target device. Verify the device path carefully with lsblk. Writing to the wrong device will destroy data irreversibly. 

sudo dd if=$LFS/lfs-lite.iso of=/dev/sdX bs=4M status=progress oflag=sync

Replace /dev/sdX with the USB device. After dd completes, the stick is bootable. Insert it into the target machine, select it in the BIOS boot menu, and LFS-Lite will boot live.
