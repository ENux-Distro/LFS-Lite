Chapter 9. initramfs Creation

An initramfs (initial RAM filesystem) is a compressed cpio archive that the kernel extracts into a tmpfs immediately after loading. The kernel then executes the /init script within this in-memory filesystem as PID 1. Its sole purpose is to locate and mount the real root filesystem, then hand control over via switch_root.

Approximate time: < 5 minutes
Output size: 1–3 MB (compressed)

9.1. What is an initramfs?

Without an initramfs, the kernel would need all drivers necessary to mount the root filesystem compiled in — including disk drivers, partition detection, and filesystem support. The initramfs approach is more modular: a tiny BusyBox environment handles device detection and mounting, then immediately hands control to the real system.

The initramfs lifecycle is brief:

  1. Kernel extracts the cpio archive into a tmpfs.
  2. Kernel executes /sbin/init (our script).
  3. The script mounts /proc, /sys, /dev.
  4. It locates the real root device from the kernel command line.
  5. It mounts the real root at /mnt/root.
  6. switch_root pivots into the new root — the initramfs is freed from RAM.

9.2. initramfs Directory Structure

The staging directory was created in Section 6.5. Verify it contains the expected structure: 

export INITRAMFS=/mnt/lfs-lite/initramfs
find $INITRAMFS -maxdepth 2 | sort

Expected output includes:

/mnt/lfs-lite/initramfs/bin/busybox
/mnt/lfs-lite/initramfs/bin/sh
/mnt/lfs-lite/initramfs/bin/mount
/mnt/lfs-lite/initramfs/bin/switch_root
/mnt/lfs-lite/initramfs/dev/
/mnt/lfs-lite/initramfs/mnt/root/
/mnt/lfs-lite/initramfs/proc/
/mnt/lfs-lite/initramfs/sbin/
/mnt/lfs-lite/initramfs/sys/

9.3. Creating Essential Device Nodes

The initramfs requires /dev/console and /dev/null as real character device files. These cannot be symlinks and require root privileges: 

sudo mknod -m 600 $INITRAMFS/dev/console c 5 1
sudo mknod -m 666 $INITRAMFS/dev/null    c 1 3

Device numbers:

c 5 1 — console

Character device, major 5 (TTY driver), minor 1 (system console). These are fixed ABI values defined by the kernel and documented in Documentation/admin-guide/devices.txt.

c 1 3 — null

Character device, major 1 (memory driver), minor 3 (null device). Discards all writes; reads return EOF.

9.4. Writing the initramfs /init Script

The /init script is the first program the kernel executes. It must be robust: if it exits or crashes, the kernel panics. 

cat > $INITRAMFS/sbin/init << "EOF"
#!/bin/sh
#
# LFS-Lite initramfs /init
# Runs as PID 1 in the initial RAM filesystem.
# Mounts the real root and pivots into it.
#

mount -t proc     proc     /proc
mount -t sysfs    sysfs    /sys
mount -t devtmpfs devtmpfs /dev

exec > /dev/console 2>&1 < /dev/console

echo "LFS-Lite initramfs starting..."

# Parse kernel command line for root= parameter
ROOT=""
for param in $(cat /proc/cmdline); do
    case "$param" in
        root=*) ROOT="${param#root=}" ;;
    esac
done

if [ -z "$ROOT" ]; then
    echo "ERROR: No root= on kernel command line. Dropping to shell."
    exec /bin/sh
fi

echo "Waiting for root device: $ROOT"
attempts=0
while [ ! -b "$ROOT" ] && [ $attempts -lt 20 ]; do
    sleep 0.5
    attempts=$((attempts + 1))
done

if [ ! -b "$ROOT" ]; then
    echo "ERROR: Root device $ROOT did not appear."
    exec /bin/sh
fi

echo "Mounting $ROOT ..."
mount -o rw "$ROOT" /mnt/root

if [ $? -ne 0 ]; then
    echo "ERROR: Failed to mount $ROOT."
    exec /bin/sh
fi

echo "Switching to real root..."
mount --move /proc /mnt/root/proc
mount --move /sys  /mnt/root/sys
mount --move /dev  /mnt/root/dev

exec switch_root /mnt/root /sbin/init

echo "ERROR: switch_root failed."
exec /bin/sh
EOF

chmod +x $INITRAMFS/sbin/init

Note

The script uses #!/bin/sh, which resolves to the BusyBox ash shell via the symlink created in Section 6.5. POSIX sh syntax is used throughout — no bashisms.

9.5. Packaging the initramfs

Package the staging directory into a gzipped cpio archive and place it in the boot directory: 

cd $INITRAMFS
find . | cpio --create --format=newc 2>/dev/null | \
    gzip -9 > $LFS_ROOT/boot/initramfs.cpio.gz

Verify the archive:

ls -lh $LFS_ROOT/boot/initramfs.cpio.gz

# List contents to confirm /sbin/init and /bin/busybox are present
zcat $LFS_ROOT/boot/initramfs.cpio.gz | cpio --list | grep -E 'init|busybox|switch'

A typical LFS-Lite initramfs is between 1 and 3 MB. If it is significantly larger, review the BusyBox configuration for unnecessary applets with make menuconfig.
